The CIMA3D mark, a 3D-printer head and its extrusion cone, copied from the association's Inkscape file (same path, 322 × 320). Use it through `<img>`; each file has its colour baked in.

- `cima3d-mark.svg`: the main mark, a left-to-right gradient from `cima-violet` (#8822ff) to `cima-magenta` (#f11eff). Use it on `background` in light and dark.
- `cima3d-mark-white.svg`: the mark in white (#ffffff). Use it on `primary`, on the dark `secondary` fill, and on photos.
- `cima3d-mark-violet.svg`: the mark in flat `cima-violet` (#8822ff), for one-colour printing, stamps and laser engraving.
